03 / Capabilities

Three habits.
One steady helper.

Each piece does one job well, then hands off to the next.

01 / Assistant

A helper with a brief.

Hand it a role, a tone and a set of limits. It sticks to them until you say otherwise.

02 / Memory

Context you control.

It keeps what is useful, shows you what it kept, and lets you trim anything that should go.

03 / Models

Swap the engine.

Pick another engine for another task without losing the thread you already built.

05 / How it runs

From a request
to a result.

  1. 01 / Connect

    Plug in
    your engines.

    Add the models you already use and set which one answers what.

  2. 02 / Remember

    Let it
    take notes.

    Useful facts are saved as you go, and every note can be opened and edited.

  3. 03 / Delegate

    Give it
    a task.

    Describe the outcome. Boobot picks the engine and brings the context along.

  4. 04 / Refine

    Correct it,
    keep going.

    Feedback is stored, so the next answer starts closer to what you wanted.

Community
